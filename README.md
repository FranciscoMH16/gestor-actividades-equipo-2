# gestor-actividades-equipo-2
Aplicación web desarrollada como actividad de trabajo colaborativo con GitHub

## Tecnologias usadas

-HTML5
-CSS
-JavaScript

## Funcionalidades

- Registro de actividades con nombre, descripcion, responsable y prioridad.
- Validacion de campos obligatorios en el formulario.
- Listado visual de actividades registradas.
- Visualizacion de prioridad (alta/media/baja) y estado (pendiente/en progreso/completada).

## Instalación y ejecución

1.- Clonar el repositorio:

git clone https://github.com/FranciscoMH16/gestor-actividades-equipo-2.git

2.- Entrar a la carpeta del proyecto:

cd gestor-actividades-equipo-2

3.- Abrir el archivo `index.html` en el navegador (doble clic)

No requiere instalacion de dependencias adicionales.

## Estado del proyecto

En desarrollo - actividad colaborativa de practica con Git y GitHub (ramas, issues, pull requests y resolucion de conflictos).

## Detalle de funcionalidades

-Registro de actividades: formulario donde se ingresa nombre, descripcion, responsable y prioridad de cada actividad.
-Listado de actividades: vista donde se muestran todas las actividades registradas, con su estado y prioridad diferenciados visualmente.
-Gestion de estados: cada actividad puede marcarse como pendiente, en progreso o completada.

# Notas del proyecto

Este proyecto fue desarrollado como actividad práctica de trabajo colaborativo usando Git y GitHub, con el objetivo de aplicar conceptos de control de versiones: ramas, commits, pull requests, code review y resolución de conflictos.

## Convenciones de commits

- Usar mensajes claros y descriptivos.
- Cada commit debe reflejar un cambio concreto y significativo.
- Evitar mensajes genéricos como "cambios" o "actualización".
